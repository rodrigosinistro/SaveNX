# Configurações recomendadas

| Opção | Padrão | Recomendação |
|---|---:|---|
| Backup automático ao restaurar | Ligado | Mantenha ligado. |
| Upload automático para remoto | Desligado | Ligue quando quiser que `Novo Backup` vá direto ao Drive. |
| Manter backups locais | Desligado | Ligue para ter uma segunda cópia no SD além da nuvem. |
| Exportar saves para ZIP | Ligado | Necessário para upload e recomendado para portabilidade. |
| Segurar para restaurar | Ligado | Mantenha ligado para evitar ações acidentais. |
| Mostrar apenas títulos montáveis | Ligado | Mantenha ligado para esconder entradas que não podem ser abertas. |
| Escrita em saves de sistema/NAND | Desligado | Não habilite sem entender o risco. Não é necessária para saves comuns de jogos. |

Para um fluxo simples de nuvem, ligue `Upload automático para remoto` e, opcionalmente, `Manter backups locais`. A pasta remota por usuário e título é aplicada independentemente dessas preferências.
